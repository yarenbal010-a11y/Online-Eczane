# Online Eczane | C# Windows Forms

C# ve .NET 8 Windows Forms kullanılarak geliştirilmiş, kullanıcıların ürünleri inceleyebildiği ve sepet işlemleri gerçekleştirebildiği bir masaüstü eczane uygulamasıdır.

Bu proje, Görsel Programlama dersi kapsamında nesne yönelimli programlama, kullanıcı arayüzü tasarımı ve veritabanı işlemlerini uygulamak amacıyla geliştirilmiştir.

## Kullanılan Teknolojiler

- C#
- .NET 8
- Windows Forms
- SQLite
- Visual Studio

## Projenin Özellikleri

- Kullanıcı kayıt ve giriş ekranları
- Kullanıcı dostu masaüstü arayüzü
- Ürünlerin kategorilere göre listelenmesi
- Sepete ürün ekleme ve sepetten ürün çıkarma
- Alışveriş işlemlerinin yönetimi
- Rahatsızlık kategorilerine göre ürün önerilerinin görüntülenmesi
- SQLite veritabanı ile veri yönetimi

## Projenin Amacı

Bu projede C# Windows Forms kullanılarak çok ekranlı bir masaüstü uygulaması geliştirilmesi, kullanıcı etkileşimlerinin yönetilmesi ve veritabanı bağlantılarının gerçekleştirilmesi hedeflenmiştir.

## Çalıştırma

1. Bilgisayarınızda Visual Studio ve .NET masaüstü geliştirme bileşenlerinin kurulu olması gerekir.
2. Projeyi indirin veya GitHub üzerinden klonlayın.
3. `OnlineEczane.csproj` dosyasını Visual Studio ile açın.
4. Gerekli NuGet paketlerini geri yükleyin.
5. SQLite veritabanının uygun konumda olduğundan emin olun.
6. Uygulamayı başlatın.

## Not

Bu uygulama eğitim amacıyla geliştirilmiş bir prototiptir. Üretim ortamında kullanılmadan önce güvenlik, özellikle parola saklama ve doğrulama işlemleri açısından iyileştirilmesi gerekir.

Uygulama tıbbi danışmanlık hizmeti sunmamaktadır.
